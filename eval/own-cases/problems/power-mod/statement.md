# Modular power

Read `a`, `b` and `m` and print `a^b mod m`.

## Input

One line: `a b m` (0 ≤ a ≤ 10^9, 0 ≤ b ≤ 10^6, 1 ≤ m ≤ 10^9). `a^0` is 1.

## Output

One line: `a^b mod m`.

## Limits

Time limit: 1 second. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.

## Constraints

The lab constraints and their deductions are in `constraints.json`.
